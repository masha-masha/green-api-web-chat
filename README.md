## 🚀 Стек технологий
- **React** (Functional Components, Hooks)
- **TypeScript** (Строгая типизация)
- **CSS Modules** (Изолированные стили)
- **Vite** (Быстрая сборка)

## ✨ Основные функции
- **Авторизация**: Вход по `idInstance` и `apiTokenInstance`. Данные сохраняются в `localStorage`.
- **Создание чата**: Возможность начать диалог по номеру телефона.
- **Real-time сообщения**: Получение входящих сообщений в реальном времени через систему Polling (ReceiveNotification).
- **История переписки**: Отображение исходящих и входящих текстовых сообщений.
- **Адаптивный интерфейс**: Лаконичный дизайн в стиле WhatsApp Web.

## 🛠 Установка и запуск

1. **Клонируйте репозиторий:**
```
git clone  git@github.com:masha-masha/green-api-web-chat.git
cd green-api-web-chat.git
```
2. **Установите зависимости:**
   

```

npm install
```


3. **Запустите проект:**
   
```
npm run dev
```


4. **Откройте приложение:**
   Перейдите по адресу [http://localhost:5173](http://localhost:5173) в браузере.

## 📖 Как пользоваться

1. Получите ваши учетные данные (`idInstance` и `apiTokenInstance`) в [личном кабинете GREEN-API](https://self.green-api.com/).
2. Введите их на экране авторизации.
3. Введите номер телефона получателя в международном формате (например, `79991234567`) и нажмите **"Открыть чат"**.
4. Теперь вы можете отправлять сообщения. Входящие сообщения от собеседника появятся автоматически.

## ⚙️ Особенности реализации
- **Polling**: Поскольку браузер не может принимать Webhooks напрямую без сервера, реализован механизм периодического опроса сервера (раз в 2 секунды) для получения новых уведомлений.
- **Безопасность**: Уведомления удаляются из очереди на сервере сразу после успешного получения (`deleteNotification`), что предотвращает дублирование данных.
- **Сетевая стабильность**: При ошибках сети интервал опроса автоматически увеличивается, чтобы избежать лишней нагрузки на клиент.

## 📂 Структура проекта
- `src/api` — логика взаимодействия с REST API.
- `src/components` — модульные React-компоненты со своими стилями.
- `src/types` — описания типов TypeScript.
- `src/utils` — вспомогательные функции (форматирование номеров и т.д.).
- `src/hooks` — кастомные хуки
